# פרויקט After Effects — מסכי אולפן עם אלמנטים זזים 🎬📺

תקייה זו מכילה סקריפט שבונה **פרויקט After Effects שלם** בלחיצה אחת:
קומפוזיציה נפרדת **לכל מסך LED באולפן** — בגדלים המדויקים מהתוכנית —
כשכולן חולקות שפה ויזואלית אחת (אותם צבעים, אותם אלמנטים, אותה תנועה)
וכולן מתנגנות **בלופ חלק** של 10 שניות.

> קובץ פרויקט (‎.aep) הוא קובץ בינארי שאי אפשר לכתוב ידנית — לכן הפרויקט נבנה
> באמצעות סקריפט רשמי של אדובי (ExtendScript). מריצים אותו פעם אחת בתוך
> After Effects והוא יוצר את הכול אוטומטית. משם שומרים כ‑.aep רגיל.

## ▶️ איך מריצים (30 שניות)

1. פותחים את **Adobe After Effects** (כל גרסה מ‑CC 2018 ומעלה).
2. בתפריט: **File ‹ Scripts ‹ Run Script File...**
3. בוחרים את הקובץ **`build-moving-elements.jsx`** מהתקייה הזו.
4. זהו! הפרויקט נבנה תוך שניות. שומרים עם **Ctrl+S** (או Cmd+S במק) כקובץ ‎.aep.

## 📺 01 - Studio Screens — מסך לכל פינה באולפן

לפי סקיצת המסכים ששלחת:

| קומפוזיציה | גודל (פיקסלים) | מיקום באולפן |
|---|---|---|
| `BackWall_Main_3200x1200` | 3200×1200 | קיר אחורי ראשי (מאחורי המגישים) |
| `BackWall_Side_2800x1200` | 2800×1200 | קיר אחורי משני |
| `Side_A_1600x1200` | 1600×1200 | מסך צד 1 |
| `Side_B_1600x1200` | 1600×1200 | מסך צד 2 |
| `Vertical_800x1600` | 800×1600 | פאנל אנכי צר (בין המסכים) |
| `Square_1600x1600` | 1600×1600 | מסך רבוע (קצה הסט) |
| `Ticker_2880x270` | 2880×270 | סטריפ עליון — שורת אלמנטים נעה |

- מסכים באותו גודל (`Side_A` / `Side_B`) מקבלים **פריסה שונה במראה** (היפוך
  והזזה של האלמנטים) כדי שלא ייראו זהים — אבל באותה שפה בדיוק.
- הסטריפ הצר (2880×270) מקבל פריסת "טיקר": שורת אלמנטים קטנים שנעה לרוחב
  ומתחברת לעצמה בלופ מושלם.
- כל הקומפוזיציות 10 שניות / 30fps ומתנגנות בלופ בלי "קפיצה" — אפשר לרנדר
  פעם אחת ולנגן ברצף על המסכים כל הערב.

## 🎨 התאמה אישית — החלפת "לוק" לכל אירוע

הפלטה הנוכחית: **כהה + אדום/מג'נטה/זהב** — בשפה של האולפן.
כדי להחליף לוק (למשל לאירוע אחר):

- **צבעים** — בראש `build-moving-elements.jsx` יש אובייקט `COLORS`.
  הערכים הם RGB בטווח 0–1. משנים ומריצים שוב — **כל 7 המסכים מתעדכנים יחד**.
- **משך הלופ** — `DUR = 10` (שניות). מומלץ מספר שלם כדי שהלופ יישאר חלק.
- **מהירות/עוצמת תנועה** — בפונקציה `applyAnim` (מהירות סיבוב, משרעת ריחוף וכו').
- **פריסת האלמנטים** — המערך `LAYOUT` קובע מיקום (באחוזים מגודל המסך) וגודל,
  ולכן אותה פריסה עובדת על כל יחסי הגובה-רוחב.

## 🎥 ייצוא (רינדור) למסכי האולפן

- לכל מסך: בוחרים את הקומפוזיציה שלו ‹ **File ‹ Export ‹ Add to Adobe Media
  Encoder Queue** ‹ H.264 (או הפורמט שמערכת הנגינה של המסכים דורשת),
  ברזולוציה המקורית של הקומפוזיציה — בלי לשנות גודל.
- מכיוון שהכול בלופ מושלם, מגדירים בנגן של המסכים **Loop** וזהו.
- **עם רקע שקוף** (לשכבה מעל תוכן אחר): רינדור מ‑Render Queue בפורמט
  QuickTime עם ערוץ אלפא (RGB+Alpha).
