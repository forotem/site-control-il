# Geometric Parallax Loop — קובץ לאפטר אפקטס

סקריפט שבונה לבד את כל הפרויקט באפטר אפקטס: אנימציית מושן-גרפיקס מופשטת עם
צורות גיאומטריות נועזות בכחול, אדום וכתום, ועמודים לבנים מחורצים — הכל נע ימינה
בתנועה איטית ויציבה, בשלושה מישורי פרלקס, בלופ מושלם של דקה.

## איך מריצים

1. פותחים את After Effects (גרסה CC 2019 ומעלה).
2. `File ‹ Scripts ‹ Run Script File…`
3. בוחרים את `after-effects/geometric-parallax-loop.jsx`.
4. הסקריפט בונה תיקייה בפרויקט ופותח את הקומפוזיציה
   **MAIN • Geometric Parallax Loop**.

אם לא קורה כלום — מפעילים ב־`Preferences ‹ Scripting & Expressions` את
`Allow Scripts to Write Files and Access Network`.

> אין צורך לשמור קובץ `.aep` מראש: הסקריפט הוא "המקור". משנים פרמטר, מריצים
> שוב, ומקבלים גרסה חדשה. אחרי הבנייה שומרים רגיל ב־`File ‹ Save As`.

## מה נוצר

| קומפוזיציה | תפקיד |
|---|---|
| `MAIN • Geometric Parallax Loop` | 3840×2160, 30fps, 60 שניות — הקומפ לרנדר |
| `TILE • Back (navy field)` | רקע כחול עמוק עם פאנלים ורצפה |
| `TILE • Mid (colour blocks)` | הבלוקים הצבעוניים: כתום, ורוד־מג'נטה, סגול, מדרגות אדומות |
| `TILE • Front (columns)` | העמודים הלבנים המחורצים |
| `COL • wide` / `COL • narrow` | עמוד בודד — חריצים, הצללה וקצוות מעוגלים |

## איך הלופ עובד

כל מישור הוא "אריח" אחד שחוזר על עצמו אינסופית באמצעות אפקט **Motion Tile**,
והתנועה נעשית בביטוי (expression) לינארי על `Tile Center`. כיוון שהמרחק שכל
מישור עובר הוא כפולה שלמה של רוחב האריח שלו, הפריים בשנייה 60 זהה בדיוק לפריים 0
— לופ נקי בלי חיתוך.

מהירויות הפרלקס (עדינות, שכבה קרובה יותר = מהירה יותר):

| מישור | רוחב אריח | מרחק בלופ | מהירות |
|---|---|---|---|
| אחורי (רקע כחול) | 1280 px | 1280 px | ~21 px/s |
| אמצעי (בלוקים צבעוניים) | 1920 px | 1920 px | ~32 px/s |
| קדמי (עמודים) | 1536 px | 3072 px | ~51 px/s |

בנוסף, המישור האמצעי והקדמי "נושמים" אנכית בתנועת סינוס זעירה (6 ו־11 פיקסלים),
מחזור אחד בדיוק לכל לופ — כדי שהתנועה לא תרגיש מכנית.

## שינויים מהירים

הכל בראש הקובץ, בבלוק `CFG`:

- `loop` — אורך הלופ בשניות. משנים ל־30 ומקבלים לופ של חצי דקה (המהירות מוכפלת).
- `dir` — כיוון: `-1` ימינה, `1` שמאלה. **אם התנועה יוצאת בכיוון ההפוך, זה
  המתג היחיד שצריך להזיז.**
- `travel` לכל מישור — לשלוט במהירות ובעומק הפרלקס.
  חובה שיהיה כפולה שלמה של `tile`, אחרת הלופ נשבר.
- `grade` / `grain` — כיבוי שכבת הגוון החם + הוינייטה, וכיבוי הגריין.

הצבעים כולם בבלוק `PALETTE` (קודי HEX), והגיאומטריה של כל אריח מוגדרת כרשימת
נקודות בפונקציות `buildTileBack` / `buildTileMid` / `buildTileFront` — אפשר
להזיז קודקוד ולהריץ מחדש.

## רנדר

`Composition ‹ Add to Render Queue`, או ל־MP4 דרך Media Encoder.
לרנדר של לופ: משאירים את טווח העבודה 0–60 שניות. הפריים האחרון (שנייה 60) לא
נכלל בטווח, ולכן אין כפילות פריים בתפר.
