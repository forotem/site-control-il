# פרויקט After Effects — אלמנטים זזים 🎬

תקייה זו מכילה סקריפט שבונה עבורך **פרויקט After Effects שלם** בלחיצה אחת:
אלמנטים גרפיים זזים בכמה גדלים וצורות, עם אנימציות שמתנגנות בלופ חלק.

> קובץ פרויקט (‎.aep) הוא קובץ בינארי שאי אפשר לכתוב ידנית — לכן הפרויקט נבנה
> באמצעות סקריפט רשמי של אדובי (ExtendScript). מריצים אותו פעם אחת בתוך
> After Effects והוא יוצר את הכול אוטומטית. משם שומרים כ‑.aep רגיל.

## ▶️ איך מריצים (30 שניות)

1. פותחים את **Adobe After Effects** (כל גרסה מ‑CC 2018 ומעלה).
2. בתפריט: **File ‹ Scripts ‹ Run Script File...**
3. בוחרים את הקובץ **`build-moving-elements.jsx`** מהתקייה הזו.
4. זהו! הפרויקט נבנה תוך שניות. שומרים עם **Ctrl+S** (או Cmd+S במק) כקובץ ‎.aep.

> אם מופיעה שגיאת הרשאות סקריפטים: **Edit ‹ Preferences ‹ Scripting & Expressions**
> ומסמנים ✔ **Allow Scripts to Write Files and Access Network** (לא חובה לרוב הגרסאות).

## 📦 מה נוצר בפרויקט

### 01 - Master Comps (קומפוזיציות מוכנות, 10 שניות, 30fps)
| קומפוזיציה | גודל | מתאים ל־ |
|---|---|---|
| `Showcase_FullHD_1920x1080` | 1920×1080 (16:9) | יוטיוב, אתר, מצגות |
| `Showcase_Square_1080x1080` | 1080×1080 (1:1) | פוסט אינסטגרם / פייסבוק |
| `Showcase_Vertical_1080x1920` | 1080×1920 (9:16) | סטורי, רילס, טיקטוק |

### 02 - Elements (11 אלמנטים לשימוש חוזר, רקע שקוף)
| אלמנט | צורה וגודל | אנימציה |
|---|---|---|
| `Circle_Small_Pulse` | עיגול קטן כתום | פעימה + ריחוף |
| `Circle_Big_Float` | עיגול גדול כחול | ריחוף איטי |
| `Ring_Pulse` | טבעת טורקיז | פעימה + שקיפות נושמת |
| `Square_Small_Spin` | ריבוע קטן ורוד | סיבוב + ריחוף |
| `Square_Big_Rounded_Float` | ריבוע גדול מעוגל סגול | ריחוף + סיבוב הפוך |
| `Triangle_Spin` | משולש צהוב | סיבוב + ריחוף |
| `Hexagon_Rotate` | משושה (קו מתאר) | סיבוב + פעימה |
| `Star_Twinkle` | כוכב צהוב | נצנוץ (סיבוב+פעימה+שקיפות) |
| `Bar_Sway` | פס מעוגל טורקיז | תנועה הצידה |
| `Cross_Spin` | פלוס לבן | סיבוב מהיר |
| `Dots_Trio_Bounce` | 3 נקודות צבעוניות | קפיצה בגלים |

כל האנימציות בנויות על **Expressions** ולכן מתנגנות **בלופ מושלם** — אפשר לרנדר
את 10 השניות ולנגן ברצף בלי "קפיצה".

## 🎨 התאמה אישית

- **צבעים** — בראש הקובץ `build-moving-elements.jsx` יש אובייקט `COLORS`.
  הערכים הם RGB בטווח 0–1 (למשל `[0.20, 0.47, 0.96]` = כחול). שנו והריצו שוב.
- **משך** — שנו את `DUR = 10` (שניות). מומלץ להשאיר מספר שלם כדי שהלופ יישאר חלק.
- **מהירות/עוצמת תנועה** — בתוך הפונקציה `applyAnim` אפשר לשנות מהירות סיבוב,
  משרעת ריחוף וכו'.
- **פריסה במסכים** — המערך `LAYOUT` קובע איפה כל אלמנט יושב (באחוזים מגודל
  הקומפוזיציה) ובאיזה גודל.

אחרי כל שינוי פשוט מריצים את הסקריפט שוב בפרויקט חדש.

## 🎥 ייצוא (רינדור)

- **וידאו לאתר/רשתות:** בוחרים קומפוזיציה ‹ **File ‹ Export ‹ Add to Adobe Media Encoder Queue** ‹ פורמט H.264.
- **עם רקע שקוף** (לשכבה מעל וידאו אחר): רינדור מ‑Render Queue בפורמט
  QuickTime עם ערוץ אלפא (RGB+Alpha), או ייצוא כל אלמנט בנפרד מתקיית `02 - Elements`.

## 💡 טיפים

- האלמנטים בתקיית `02 - Elements` הם קומפוזיציות עצמאיות — אפשר לגרור כל אחד
  לכל פרויקט אחר, לשכפל, לצבוע מחדש ולהגדיל בלי לאבד איכות (וקטורי).
- בקומפוזיציות הראשיות מופעל `Collapse Transformations` כך שהצורות נשארות חדות
  בכל קנה מידה.
